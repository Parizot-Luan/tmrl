- Run : `SAC_CNN_GRU_PROGRESS_v2`
- Branche Git : `v2`
- Tag : `v2.0.0`
- Config versionnée : `configs/v2.0.json`
- Repart de zéro : `RESET_TRAINING=true`
- Archive V1 : `~/TmrlData/versions/v1/`

## Réseau

Même architecture que V1 : `ImageProgressActorCritic` (`cnn_gru_progress`).

- Encodeur image par frame : `ImageProgressFrameEncoder`
  - Conv 32 stride 2, GroupNorm, SiLU
  - Conv 64 stride 2, GroupNorm, SiLU
  - ResidualBlock 64
  - Conv 128 stride 2, GroupNorm, SiLU
  - ResidualBlock 128
  - `AdaptiveAvgPool2d(1)` + projection 128
- Encodeur temporel : GRU 128 → 128 sur 4 frames
- Encodeur scalaire : vitesse, rapport, RPM, progression, 2 actions précédentes
- Acteur : MLP 256 → 256 → 3 actions
- Deux critiques `q1` / `q2` avec encodeurs séparés

## Optimisations image

- Fenêtre Trackmania : `480×270`
- Crop haut : `40 %` → 108 px retirés
- Crop bas : `7 %` → 19 px retirés
- Image source après crop : `480×143`
- Resize : `48×48`
- Grayscale : oui
- Historique : 4 frames
- Observation image : `(4, 48, 48)`
- Aucun crop à gauche/droite

Justification :
- suppression du ciel, du HUD haut et du HUD bas ;
- conservation de la route et de l'horizon utile ;
- réduction du coût des convolutions ;
- architecture compatible car l'encodeur utilise des convolutions et un pooling adaptatif.

## AMP

- `USE_AMP=true` dans `ENV`
- Trainer : `torch.autocast("cuda", dtype=torch.float16)` + `GradScaler`
- Deux scalers séparés : un pour les critiques, un pour l'acteur
- Optimiseur d'entropie conservé en fp32
- Worker/inférence : fp32 pour stabiliser les actions
- Fallback prévu : désactiver AMP ou passer en bfloat16 si instabilité

## Correction des replays

- La sauvegarde est déplacée dans `wait()`, avant `send_control()` et `reset_race()`.
- Le ghost est encore disponible au moment de la demande.
- Premier replay : immédiat au premier reset.
- Ensuite : au maximum une sauvegarde toutes les 30 minutes.
- Timeout de connexion ajouté sur le port `10000`.
- Logs ajoutés : `Replay save requested` et warning en cas d'échec.
- Vérification attendue : `Replay saved at ...` dans `Openplanet.log` + fichier `.Replay.Gbx`.
