## Réseau

Architecture `ImageProgressActorCritic` (`cnn_gru_progress`).

- Encodeur image par frame : `ImageProgressFrameEncoder`
  - Conv 32 stride 2, GroupNorm, SiLU
  - Conv 64 stride 2, GroupNorm, SiLU
  - ResidualBlock 64
  - Conv 128 stride 2, GroupNorm, SiLU
  - ResidualBlock 128
  - `SpatialSoftmax` fp32 (`2 × 128` sorties)
  - Projection `256 → 128`
- Encodeur temporel : GRU 128 → 128 sur 4 frames
- Encodeur scalaire : vitesse, rapport, RPM, progression, 2 actions précédentes
- Acteur : MLP 256 → 256 → 3 actions
- Critiques `q1` / `q2` : encodeur image **partagé**, têtes Q séparées
- Dernière couche Q, `mu`, `log_std` et pertes sensibles conservées en fp32 sous AMP

## Optimisations image

- Fenêtre Trackmania : `480×270`
- Géométrie réelle récupérée via `xdotool` après déplacement/redimensionnement
- Offsets Linux : `LINUX_X_OFFSET=0`, `LINUX_Y_OFFSET=0`
- Crop haut : `25 %` → 68 px retirés
- Crop bas : `7 %` → 19 px retirés
- Image source après crop : `480×183` (ratio `2,62:1`)
- Resize : `96×32` avec `cv2.INTER_AREA`
- Grayscale : oui
- Historique : 4 frames
- Observation image : `(4, 32, 96)`
- Aucun crop à gauche/droite

Justification :

- suppression du ciel, du HUD haut et du HUD bas ;
- conservation de la route et de l'horizon utile ;
- réduction du coût des convolutions ;
- `SpatialSoftmax` conserve la localisation spatiale des bords de piste.

## AMP

- `USE_AMP=true` dans `ENV`
- Trainer : `torch.autocast("cuda", dtype=torch.float16)` + `GradScaler`
- Deux scalers séparés : un pour les critiques, un pour l'acteur
- Optimiseur d'entropie conservé en fp32
- Worker/inférence : fp32 pour stabiliser les actions
- Fallback prévu : désactiver AMP ou passer en bfloat16 si instabilité

## Correction des replays

- La sauvegarde est effectuée dans `wait()`, avant `send_control()` et `reset_race()`.
- Le ghost est encore disponible au moment de la demande.
- Premier replay sauvegardé après le premier épisode, puis au maximum une fois toutes les 30 minutes.
- Timeout de connexion sur le port `10000`.
- Logs : `Replay save requested` et warning en cas d'échec.
- Vérification : `Replay saved at ...` dans `Openplanet.log` + fichier `.Replay.Gbx`.
