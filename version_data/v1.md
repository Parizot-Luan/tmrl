## Réseau

Modèle : `ImageProgressActorCritic` (`cnn_gru_progress`).

- Encodeur image par frame : `ImageProgressFrameEncoder`
  - Conv 32 canaux, noyau 3, stride 2, GroupNorm, SiLU
  - Conv 64 canaux, noyau 3, stride 2, GroupNorm, SiLU
  - ResidualBlock 64 canaux
  - Conv 128 canaux, noyau 3, stride 2, GroupNorm, SiLU
  - ResidualBlock 128 canaux
  - `AdaptiveAvgPool2d(1)` puis projection linéaire vers 128
- Encodeur temporel : GRU 128 → 128 sur les 4 frames
- Encodeur scalaire : MLP 128 → 128 avec LayerNorm/SiLU
  - vitesse, rapport, RPM, progression, 2 actions précédentes
- Acteur : MLP 256 → 256 → 3 actions `[gas, brake, steer]`
- Critiques : `q1` et `q2`, chacun avec son propre encodeur image + GRU + MLP
- Les critiques cibles réutilisent la même structure pour le backup SAC.
